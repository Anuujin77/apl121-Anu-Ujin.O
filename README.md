## Бодлого

Улаанбаатарт өвөл утаа их байдаг тул би энэ сэдвийг сонгосон. Миний программ 7 өдрийн PM2.5 хэмжилтийг уншиж:

1. өдөр бүрийг AQI ангиллаар («Сайн» … «Аюултай») ангилж, тэмдэгтэй хүснэгт хэвлэнэ;
2. хамгийн бохир 3 өдрийг эрэмбэлж гаргана.

## Өөрийн тогтоосон дүрмүүд

**1. AQI ангилал** (24 цагийн PM2.5, µg/m³). Хил нь US EPA-гийн 2024 оны шинэчилсэн утга:

| PM2.5 | Ангилал | Тэмдэг |
|---|---|---|
| 0 – 9.0 | Сайн | |
| 9.1 – 35.4 | Дунд зэрэг | |
| 35.5 – 55.4 | Эмзэг бүлэгт хортой | `*` |
| 55.5 – 125.4 | Хортой | `*` |
| 125.5 – 225.4 | Маш хортой | `!` |
| 225.5+ | Аюултай | `!` |

**2. Тэмдэг:** `*` = 24 цагийн стандарт (35)-аас давсан; `!` = маш хортой ба түүнээс дээш.

**3. Зөв оролт:** 0 – 1000. Сөрөг тоо боломжгүй, 1000-аас дээш бол мэдрэгчийн алдаа гэж үзнэ. Буруу бол "Буруу утга!" гаргаж дахин асууна.

**4. Тэнцүү утга:** эрэмбэлэхэд эрт өдөр нь түрүүлнэ.

## Псевдокод

```
ЭХЛЭХ
  pm[7] (бодит), day[7] (бүхэл) массив зарлах

  // 2. Оролт + шалгалт
  i = 0-ээс 6 хүртэл:
      "Өдөр (i+1) PM2.5 (0-1000):" хэвлэх
      pm[i]-г унших
      pm[i] < 0 ЭСВЭЛ pm[i] > 1000 байх ХООРОНД:
          "Буруу утга! 0-1000 хооронд оруулна уу:" хэвлэх
          pm[i]-г дахин унших
      day[i] = i + 1

  // 3. Хүснэгт
  "Өдөр | PM2.5 | Ангилал | Тэмдэг" хэвлэх
  i = 0-ээс 6 хүртэл:
      cat  = Category(pm[i])
      mark = Mark(pm[i])
      day[i] | pm[i] | cat | mark хэвлэх

  // 4. Bubble sort (ихээс бага)
  i = 0-ээс 5 хүртэл:
      j = 0-ээс (5 - i) хүртэл:
          ХЭРЭВ pm[j] < pm[j+1] БОЛ
              pm[j] ба pm[j+1]-г солих
              day[j] ба day[j+1]-г солих

  // 5. Хамгийн бохир 3 өдөр
  "Хамгийн бохир 3 өдөр:" хэвлэх
  i = 0-ээс 2 хүртэл:
      (i+1) ". Өдөр " day[i] " — " pm[i] хэвлэх
ДУУСАХ

ФУНКЦ Category(p) → текст
  ХЭРЭВ p <= 9 БОЛ "Сайн"
  ҮГҮЙ БӨГӨӨД p <= 35.4 БОЛ "Дунд зэрэг"
  ҮГҮЙ БӨГӨӨД p <= 55.4 БОЛ "Эмзэг бүлэгт хортой"
  ҮГҮЙ БӨГӨӨД p <= 125.4 БОЛ "Хортой"
  ҮГҮЙ БӨГӨӨД p <= 225.4 БОЛ "Маш хортой"
  ҮГҮЙ БОЛ "Аюултай"

ФУНКЦ Mark(p) → текст
  ХЭРЭВ p > 125.4 БОЛ "!"
  ҮГҮЙ БӨГӨӨД p > 35.4 БОЛ "*"
  ҮГҮЙ БОЛ ""
```
